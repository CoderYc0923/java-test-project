# 支付中心流程（当前设计）

## 下单

```text
POST /admin/order/mock + requestId
  → Redis 幂等 order:idempotent:{requestId}
  → 落库：待付款 + 未支付
```

## 支付（必须走回调）

```text
用户点付钱
  → PUT /admin/order/mockPay/{id}
  → requestPay：校验待付款，触发模拟微信 @Async
  → （延迟 ~1.5s）POST /admin/order/mockPay/notify
  → handleNotify：
       验签(HMAC) → 时间窗 → nonce 去重
       → 核金额 → 锁 → CAS → 待接单+已支付
```
