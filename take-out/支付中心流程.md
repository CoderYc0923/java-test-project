# 支付中心流程（真实式：确认页）

```text
管理端点「模拟支付」
  → PUT /admin/order/mockPay/{id}
  → HTTP POST 假微信 /v3/pay/transactions/native   （统一下单，NOTPAY）
  → 前端打开假微信确认页
       http://127.0.0.1:9090/mock/pay/checkout?out_trade_no=ORD...
  → 用户在确认页点「确认支付」
  → POST 假微信 /mock/pay/confirm
  → 假微信 HTTP POST 商户 /admin/order/mockPay/notify（HMAC）
  → 外卖验签 + CAS → 待接单 + 已支付
  → 管理端轮询待付款列表，该单消失即成功
```

对应真微信：扫码/调起支付收银台 → 用户输密码 → 微信异步 notify 商户。
